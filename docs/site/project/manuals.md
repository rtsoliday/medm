# Standalone manuals

The complete QtEDM reference is available inside the application under **Help > Help Topics** (F1) and as a standalone HTML document. These copies do not require the documentation website or JavaScript.

In the Help window you can:

- **Browse** with the topic sidebar, which follows along as you scroll.
- **Search** the whole manual with **Find in help** (Ctrl+F, or Command+F on macOS). Enter or F3 goes to the next match, and Shift+Enter or Shift+F3 goes back.
- **Close** it with Escape. Reopening Help brings back the same window.

The **Help** menu also has **Keyboard Shortcuts**, **Online Manual** (opens this website), and **About QtEDM** (versions and credits). In each palette, **Help** or F1 opens that palette's section of the manual, and the Object Palette's **Object Index** opens the widget list.
